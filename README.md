# Decentralized in Name Only: The Centralization of DAO Labor
The paper can be found [here](https://dl.acm.org/doi/10.1145/3774904.3792849).

## Dataset

The dataset used in this research is available [here](https://drive.google.com/drive/folders/1lH_lzFTCyIPTOxHl_XXJ1allOjnjTDOT?usp=sharing).

The file named "dao_task_contributor_opensource_V1.csv" is used for analyses and experiments in this paper.
